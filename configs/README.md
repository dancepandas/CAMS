# configs/ — 管道配置

| 文件 | 作用 |
|---|---|
| `pipeline.yaml` | 基准配置：流域范围（French Broad River）、15 个 USGS 断面、数据路径、下载参数（线程数、代理、产品分段表）、训练时段。S.14（短历史 2015-06 起）用它 |
| `pipeline_rain1990.yaml` | S.18 配置：与基准配置相同，但 `period.start = 1990-01-01`，降雨文件指向 `data/rain_1990_2024.nc`（AORC 1990–2015.6 + MRMS 2015.6–2024.12），面雨量指向 `data/area_rain_1990_2024.npz` |
| `sites_french_broad.csv` | 15 个断面的站号、名称、经纬度、USGS 公布汇水面积 |

## 关键约定

- 两份配置的**网格、站序、模型结构、训练超参完全一致**，只有降雨历史长度
  不同——这是 S.14 vs S.18 公平比较的前提。
- 训练切分固定 `split_dates = ["2023-01-01", "2024-01-01"]`：训练目标早于
  2023-01-01，2023 只用于早停，2024 只做最终评估。
- `fetch.rain_products` 是 MRMS 产品分段表：2020-11 之前用
  `GaugeCorr_QPE_01H`，之后用 `MultiSensor_QPE_01H_Pass2`（镜像上 Pass2
  只回溯到 2020-11）。取不到首选产品时会自动尝试另一段，自愈切换。
