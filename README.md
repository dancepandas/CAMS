# CAMS 汇流感知多断面预报模型 · 交接文档

## 一、模型解决什么问题

一个共享权重的模型，同时预报流域内多条河流上多个断面的流量过程，逐小时
起报、滚动预报最长 24 小时。CAMS 的名字对应它的两个特点：

**汇流感知**。用高程算出的流向场划定每个断面的上游汇水区，做成掩膜，去
挑选降水网格中属于该断面的那部分。同一张降雨图在不同断面下变成不同的
输入——降雨落在哪里、上游汇了多少水，模型能直接看见。

**多断面**。一套权重同时服务全流域所有断面。参考流域十五个断面的集水面积
从 14 到 4812 平方公里，跨 340 倍，共用同一个模型（MoE 双专家软门控自动分工）。

## 四、数据链（2026-09 坐标修正后的版本）

空间网格唯一真源在 `scripts/spatial_grid.py`：MRMS 全球网格 3500×7000，
左上角 (54.995N, 129.995W)，步长 0.01°；项目 128×128 目标区
纬度 35.065–36.335、经度 -83.485–-82.215（EPSG:4326），网格指纹
sha256:3be9b888…（绑定坐标实值，可发现半格偏移与方向翻转）。

降水两段拼接，拼接点 2015-06-01 只出现一次：

| 时段 | 来源 | 说明 |
|---|---|---|
| 1990-01 ~ 2015-06 | NOAA AORC v1.1 1km | S3 年度 Zarr，重投影到目标网格，float32，任一块下载失败整年报错（绝不静默补零） |
| 2015-06 ~ 2024-12 | MRMS 1h QPE | GaugeCorr（2020-10 前）/ MultiSensor Pass2（之后） |

公共时段（2015-06 起）拼接件与原 MRMS 件逐点比对最大偏差为 0。

**面雨量**（`scripts/area_rain.py`）：汇水区掩膜元素 = 每个 1km 格被流域
覆盖的比例；每小时 有效值加权和 ÷ 有效权重和，NaN 同时剔除、不当零。
`data_contract.py` 强制校验 rain/catchment/area-rain 的坐标、CRS、站序、
时间轴逐项一致，不符即报错。

## 五、模型与训练（当前主力：S 系修正版）

结构（`scripts/train.py`）：MoE 双专家，每专家 = LSTM 历史支路 + CNN 空间支路
（汇水区掩膜裁剪的 当前1h/72h累计 降雨图，掩膜池化）+ 预见期降雨 CNN，
门控按 [当前流量, 近24h均值, log面积] 软加权。约 16 万参数。

训练语义：`output_mode=level`（直接输出下一时刻标准化流量，不加锚）、
`transform=gstd`（全局标准化）、分位数损失 0.1/0.5/0.9、回看 72h、
单步模型滚动 24h、训练抽样步长 3。切分硬边界：训练目标 <2023-01-01，
2023 只验证早停，2024 只在权重冻结后评估（`assert_calendar_splits` 断言）。

## 六、当前性能（2024 测试段，逐小时起报、滚动 24h）

公平对比（同一修正数据、同结构同种子，只换降雨历史长度）：

| 指标 | S.14 修正版（2015 起） | S.18 修正版（1990 起） |
|---|---|---|
| 24h 整体中位 NSE | 0.729 | **0.758** |
| 中位 KGE | 0.603 | **0.693** |
| +6h / +12h 中位 NSE | 0.777 / 0.678 | **0.858 / 0.767** |
| 胜过持续性的站数 | 12/15 | **13/15** |
| 洪峰最高 5% 平均偏差 | -20.3%（低估） | **+10.3%** |

结论：加 1990–2015 历史降雨净收益——洪峰低估（Helene 核心病灶）大幅缓解
（纽波特 -46%→-11%），3–12h 全面变好；代价是 24h 档略退、峰现时间略晚，
三个小站（米尔斯河/比特里溪/弗莱彻）出现滚动深处正向漂移（闭环失稳，
level 模式老毛病，与数据质量无关——一步预报全面变好可证）。

实验记录与图件：`experiments/step18_compare/`（2024 超极端年）、
`experiments/step18_val_compare/`（2023 正常年，两年对照故事：
two_year_summary.txt）、coverage 图。

## 七、定稿方案与复现（2026-10-04 用户拍板）

**定稿：S.20 非对称罚版**（整条 24 步闭环轨迹 BPTT + 低估罚 1.0 / 高估罚 0.3），
底模为 S.18 修正版配方。两年评估（2023 正常年 / 2024 海伦超极端年，权重均
未见过）达标线最全：三小站 24h 偏差唯一 3/3 全进 ±10%（2024：-4.2/+6.5/+1.7%）、
中位 NSE 0.806/0.929、胜持续性 15/15、洪峰 -11.2%（远好于 S.14 基线 -20.3%）。
完整对比：`experiments/step18_compare/`（2024）、`experiments/step18_val_compare/`
（2023，含两年对照表 two_year_summary.txt）。

## 八、进行中的工作

**S.19（远期立项，用户已定调）**：分桶 LLM 方案（Chronos 式）——流量离散化
成桶、Transformer 主干、CNN 视觉塔编码降雨图多模态融合、原生概率输出。
动机：S.18 闭环实验曾证实 level 模式下"压漂移"与"保洪峰"难兼得；S.20 已用
BPTT+非对称偏差罚找到中间解（详见下方已完成的实验），分桶的价值转为
"机制上消灭复利放大"与多模态/概率输出，优先级下降。注意：分桶治漂移但治不了"训练没见过 2024 洪峰量级"的天花板，
且小站需逐站标准化（全局 gstd 会让小站挤进两三个桶）。

**已完成的实验**（详见 `experiments/step18_compare/README.md`）：

- S.14/S.18 修正版公平对比：加 1990–2015 历史降雨净收益（洪峰 -20.3%→+10.3%，
  中位 NSE 0.729→0.758），代价是三小站滚动漂移。
- S.18 闭环训练（scheduled sampling）：漂移根治（+24h 中位 NSE 0.600→0.735，
  峰现偏差 5.46h→1.69h，米尔斯河 NSE -0.063→0.659），代价是洪峰重新低估
  （+10.3%→-16.1%，仍优于 S.14 的 -20.3%）与 1~9h 略降。中位 NSE 0.758 守住。
- S.20 轨迹级可导目标的三级实验（整条 24 步轨迹 BPTT + 偏差罚）：对称罚失败
  （均衡点永远在零下）→ 单边罚（只罚低估，拆掉"往下压"捷径）**破局**——中位
  NSE 0.813、+24h 0.819、胜持续性 15/15、洪峰 -8.2%，全面项目纪录；非对称罚
  微调版（under=1.0/over=0.3）三小站 24h 偏差史上首次 3/3 全进 ±10%
  （-4.2/+6.5/+1.7%），中位 NSE 0.806、洪峰 -11.2%，为 LSTM 定稿方案。
  详见 `experiments/step18_compare/README.md` §6–§9。

  **命名澄清（2026-10-10）**：这一系列不是强化学习。整条轨迹的损失三项
  （逐步分位数损失、对持续性基准的提升量、偏差罚）全部是预测值的可导函数，
  直接反传即可，没有采样、策略梯度或基准线。破局真正的杠杆是**目标函数的
  形状**（非对称罚从物理上拆掉"把预测整体压低"这条捷径），不是优化算法。
  更早的 S.13 才试过真 RL（连续动作高斯策略 PPO），因数据稀缺失败；RL 的
  价值来自奖励不可导/必须探索，这两条我们都不占——**奖励能求导时用 RL
  只会把同样的事做得方差更大**。若将来改成分桶输出（S.19），词表式的离散
  选择才让 PPO/REINFORCE 重新自洽。

## 九、已知限制

1. **预见期降雨用实测**（完美降雨假设）。业务上线换数值预报雨后所有数字
   会打折，洪峰时段打折最狠——离线结果是乐观上界。
2. **2024 洪峰超出训练最大值**（多数站 2–4.7 倍），模型对未见量级的外推
   能力有限，这是洪峰预报的平台高度，加历史（S.18）已部分缓解。
3. **24h 档闭环漂移**：level 模式滚动放大小误差，三小站最敏感；闭环训练
   正在验证修复效果。
4. 空间分辨率 1km 对十几平方公里的小结面上不利（汇水区只有十几格）。
5. 只在 French Broad 单一流域验证过，跨流域未涉及。

## 十、复现性

全流程随机种子 `model.seed=42`。关键产物走 staging→校验→原子替换；训练
输出含 `best.pt`、`predictions.npz`、`training_manifest.json`（manifest v2
绑定数据签名与切分边界，签名不符拒绝评估）。测试见 `tests/`，当前全绿。
